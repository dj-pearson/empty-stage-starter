# READ BEFORE EDITING (US-645)
# ----------------------------
# Under RFC 9309 a crawler obeys the ONE most specific group that matches its
# user-agent and ignores every other group, including "User-agent: *". So a
# named group is not an addition to the wildcard group, it REPLACES it.
#
# That is why the private-path Disallow block is repeated verbatim in every
# group below instead of being written once under "*". The repetition is load
# bearing. Before this file was fixed, all 16 Disallow rules lived only under
# "*" while 19 named groups said "Allow: /" with no Disallow at all, which
# invited Googlebot, Bingbot, GPTBot, ClaudeBot, PerplexityBot and Applebot
# into /admin, /dashboard, /seo-dashboard, /search-traffic, /join and the
# faceted query URLs. Do not "clean up" the duplication.
#
# The paths carry no trailing slash on purpose. A prefix match means
# "Disallow: /admin/" does NOT cover "/admin", which is the actual route in
# src/App.tsx; "/admin" covers /admin, /admin/agents and /admin-dashboard.
#
# Adding a crawler means copying a whole group, block included. There is a
# test that fails if a named group is missing a rule: src/lib/robots-txt.test.ts
